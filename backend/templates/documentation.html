Using Pipeline of Pipelines

Create reviewable, auditable data transformations from stored and newly uploaded source files.

1. Sign in and choose an organization

Sign in with your invited Clerk account. Organizations control which clients and files you can access. Organization administrators can manage members and provider credentials from Organizations.

2. Start a mapping

Open Upload, select an organization, then choose an existing client or create a new one.

  • Select any stored source files shown for an existing client.
  • Optionally add new source files in the same run.
  • Upload the required target-schema JSON file for this mapping.

The client is the boundary for reusable source-file context. The target schema belongs to the mapping, not the client.

3. Review the proposed mapping

The service parses the selected files, retrieves relevant evidence, and proposes target-column mappings. Review source-table warnings, the target schema, source columns, transformation logic, and generated Polars expressions.

Save any edits before approving. Reject a mapping if the selected source files or target shape are wrong.

4. Generate and review results

Approving a mapping generates and runs the transformation. Review the results CSV, generated Python pipeline, and validation results. Confirm the result only when it is ready for delivery.

Files, runs, and outputs

  • Clients lists reusable source files, mappings, and generated deliverables.
  • Runs shows execution history for an organization.
  • Every mapping has its own downloadable target_schema.json, mapping.json, pipeline.py, and results.csv when generated.

Good practice

  • Use only files you intend to include in the mapping; source files are retained immutably.
  • Review parser warnings and low-confidence mappings before approval.
  • Keep target schemas with the run that produced the output so the result remains reproducible.
